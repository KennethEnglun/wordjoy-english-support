1. 適用範圍與聯絡方式

本政策適用於 iOS／iPadOS app「字學貓英語樂園（WordJoy English Paradise）」及此支援網站，由 GitHub 帳戶 KennethEnglun 維護。另一個名稱相近的中文學習 app 不在此政策範圍。

如有技術或私隱問題，可使用本網站列出的 GitHub 問題頁聯絡維護者。該頁公開，請只描述一般問題，不提交兒童資料或其他敏感內容。

2. 保存在裝置上的資料

App 會在本機保存學習者暱稱、年級及設定、遊戲作答及學習紀錄、錯字重溫範圍、星星、金幣、貼紙、練習包與自訂字詞。你選取的自訂字卡相片、默書工作紙圖片、辨識文字、畫重點標記、修訂內容及作答紀錄亦保存在 app 的本機資料目錄。

這些資料用於提供練習、報告、朗讀設定及再次溫習。工作紙和練習包在同一 app 內共用，學習紀錄按學習者整理；學習者檔案不是獨立登入帳戶或保密空間。

App 沒有開發者帳戶系統或開發者營運的雲端資料庫，不會把上述學習內容自動上傳給我們，也不會自行在裝置之間同步。

3. 相機、相片、辨識及朗讀

只有你使用拍攝功能時才會要求相機權限；選圖使用系統相片選取介面，處理你主動選取的圖片。你可拒絕相機權限並改用選圖，亦可在 iOS 設定撤回權限。

工作紙文字辨識和英文朗讀使用 Apple 系統框架。辨識在裝置上進行。自訂字詞的繁中翻譯建議使用 iOS Translation；系統可能先要求下載語言資料，下載後在裝置上翻譯。App 沒有將工作紙或翻譯文字傳送到開發者伺服器或第三方 AI 服務。

App 不提供錄音或以咪高峰作答功能。系統聲音、語言下載與 Apple 系統服務按 Apple 的設定及私隱政策運作。

4. Apple 購買及功能授權

買斷、付款確認及恢復購買由 Apple App Store／StoreKit 處理。App 使用 Apple 已驗證的商品及交易資料確認是否可使用進階功能，並處理等待、取消或撤銷狀態。

我們不接收你的信用卡號、Apple 帳戶密碼或付款驗證碼。Apple 會按其政策處理帳戶、付款及交易資料。恢復授權不會將你的本機學習內容傳送給開發者。

5. 廣告、分析及兒童資料

此版本沒有第三方廣告、廣告識別碼追蹤或開發者整合的使用分析／遙測 SDK。我們不出售學習資料，不建立廣告檔案，也不以本機學習內容訓練開發者的 AI 模型。

家長可使用暱稱，避免在工作紙或自訂相片中加入不必要的個人資料。家長計算用於限制購買及外部連結入口，不代表同意收集兒童個人資料。

6. 保存、刪除與備份

本機資料一般保留至你在 app 刪除相關內容或刪除 app。為了避免寫入損毀，資料儲存可保留一份先前有效的復原版本；該版本使用的圖片可能暫時保留，直至後續保存輪替。

刪除或修改工作紙不會改寫已有的作答快照，因此舊結果可能仍有題目文字及相關圖片。刪除練習包亦不會自動刪除自訂字詞庫。

如要清除整個 app 在裝置上的資料，請使用 iOS 的「刪除 App」；「卸載 App」會保留文件與資料。系統備份或裝置轉移可能包括 app 資料，取決於你的 iOS／iCloud／電腦備份設定；這些備份需在系統另行管理。Apple 的購買紀錄不會因刪除 app 而刪除。

我們沒有你的本機內容副本，無法代你查看、匯出或從伺服器刪除該內容。你可在 app 修改資料、在系統撤回權限，或按上述方式刪除裝置資料。

7. 此網站與 GitHub 支援

此網站由 GitHub Pages 提供靜態檔案，沒有我們加入的 Cookie、網站分析、追蹤像素、外部字體或資料收集表單。GitHub 作為託管服務提供者，可能按其政策處理 IP 位址、瀏覽器資訊及網頁請求紀錄。

當你主動到 GitHub 提交問題，GitHub 會處理你提交的帳戶及內容，維護者會使用問題內容作支援。這與 app 自動收集資料不同。你可在 GitHub 編輯自己的內容，或要求我們移除可由維護者控制的內容；GitHub 的保留及刪除方式以其政策為準。

8. 政策更新

如果資料處理方式改變，我們會更新此頁及更新日期，並在需要時於 app 提供相關資訊。此政策描述上方日期所對應版本的實際功能與資料處理方式。
